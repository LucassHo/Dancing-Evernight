## Setup

1. **Install dependencies**
```bash
npm install
```

2. **Create dist file for export**

3. **Build the App**
```bash
npm run build
```

4. **Run the App**
```bash
npm run start
```

## Alternative Startup with .exe
```bash
npm run package
```

App will be exported to out file, executable with evernight.exe
